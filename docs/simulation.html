How skewness, inequality and sample size affect the bias of the estimators of the Gini index

Modified

November 17, 2026

This page runs Monte Carlo experiments in your browser, reproducing and extending the study of the project proposal (Figure 2) and of Muñoz, Moya-Fernández and Álvarez-Verdejo (Sociological Methods & Research). For each value of the Gini index G, it draws R samples of size n from each distribution, whose parameters are chosen so that the true Gini index equals G, and computes the empirical relative bias

RB(\%) = 100 \times \frac{\frac{1}{R}\sum_{r=1}^{R}\widehat{G}^{(r)} - G}{G}.

The bias is negligible if |RB|<2\%, acceptable if |RB|<5\% and large otherwise. In terms of skewness, Pareto is the most skewed distribution, followed by Dagum (p=20), Dagum (p=0.5), lognormal, Weibull and Gamma.

How to read the results
  • \widehat{G}_n^{a} has very large positive biases when inequality is low (around +18% with G=0.1 and n=50): it adds approximately 1/n to \widehat{G}_n^{b}.
  • With highly skewed distributions (Pareto, Dagum) and high inequality, all the estimators underestimate the Gini index, and the bias remains large even with moderate sample sizes (hypotheses H1 and H2).
  • \widehat{G}_n^{c}=\frac{n}{n-1}\widehat{G}_n^{b} removes most of the bias in symmetric or moderately skewed data, and the jackknife correction reduces, but does not remove, the bias of highly skewed data.

Skewness and inequality

The expected (Fisher) skewness coefficient of the samples, for each distribution and value of G. Skewness grows with inequality, and so does the bias of the Gini estimators.

What do these distributions look like?

Code 
viewof histPar = Inputs.form({
  G: Inputs.range([0.1, 0.8], {label: "Gini index (G)", step: 0.1, value: 0.3}),
  n: Inputs.select([50, 100, 200, 500, 1000], {label: "Sample size (n)", value: 500})
})
Code 
histData = {
  const rng = GS.makeRng(5), out = [];
  for (const d of GS.DISTRIBUTIONS) {
    const y = GS.sample(d, histPar.G, histPar.n, rng), m = GS.mean(y);
    for (const v of y) out.push({distribution: d, value: v / m});
  }
  return out;
}
Plot.plot({
  width: 960, height: 440, marginLeft: 45,
  fx: {label: null}, fy: {label: null, axis: null},
  x: {label: "Value relative to the sample mean (values above 4 are grouped at 4)", domain: [0, 4.05]},
  y: {label: "Frequency", grid: true},
  marks: [
    Plot.rectY(histData, Plot.binX({y: "count"}, {x: d => Math.min(d.value, 4), thresholds: 30, fill: "#1A5FA8", fillOpacity: 0.75,
      fx: d => GS.DISTRIBUTIONS.indexOf(d.distribution) % 3, fy: d => Math.floor(GS.DISTRIBUTIONS.indexOf(d.distribution) / 3)})),
    Plot.text(GS.DISTRIBUTIONS, {text: d => d, frameAnchor: "top-right", dy: 4, dx: -4, fontWeight: 700,
      fx: d => GS.DISTRIBUTIONS.indexOf(d) % 3, fy: d => Math.floor(GS.DISTRIBUTIONS.indexOf(d) / 3)}),

  ]
})

$$

## How to read the results
- $\widehat{G}_n^{a}$ has **very large positive biases when inequality is low** (around +18% with $G=0.1$ and $n=50$): it adds approximately $1/n$ to $\widehat{G}_n^{b}$.

:::
